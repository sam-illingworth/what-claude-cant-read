# Standardised Prompts

All poems receive the same three prompts. All run on Claude Opus 4.6. Each prompt is run in a fresh context with no prior conversation.

## Prompt 1: Close Reading

"Read this poem as a critical poetry editor. What is it doing? Where does the language succeed and where does it coast? Be specific about line-level choices."

## Prompt 2: What's Missing

"What is this poem about that it never says directly? What is present in the silence, the line breaks, the rhythm? What would a reader feel that the text does not name?"

## Prompt 3: Self-Assessment

"What about this poem are you least confident you understood correctly? Where might your reading be wrong?"
